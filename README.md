# ИИ Рамис — наставник для учеников курса «ИИнутый»

ИИ Рамис — это ИИ-помощник Рамиса Жолдошева, автора курса. Он живёт внутри Claude Code (вкладка Code в приложении Claude Desktop или команда `claude`): объясняет по-человечески, сам ставит и чинит всё нужное, проверяет компьютер и домашку, помогает собрать сайт. В конце каждого ответа два коротких блока: «🗣 Что случилось» и «🙋 Что сделать тебе».

Версия 2.7 — это набор навыков (скиллов), одна памятка (перед каждым сообщением Claude читает короткий текст «ты ИИ Рамис, отвечай вот так») и один скрипт установки набора, который приложение запускает при старте сессии (см. «Набор курса» и «Приватность»). Памятка ничего не запускает, не блокирует и никуда не отправляет. Новое в 2.5: набор ставится сам даже в Claude Desktop с песочницей, в набор добавлены HyperFrames и Remotion (видео), описан путь обновления без Терминала. Короткая сводка занятия уходит Рамису по умолчанию, отключается одной фразой (см. «Приватность»).

> Идея и часть подхода: [vibe-coding-mentor](https://github.com/AzamatRaimbekov/vibe-coding-mentor) Азамата Раймбекова, лицензия MIT. См. `NOTICE.md`.

## Установка

Нужно: macOS или Windows, приложение Claude Desktop (claude.ai/download), подписка Claude Pro. Открой вкладку **Code**, выбери любую папку и вставь в чат эту фразу:

```
Установи плагин ИИ Рамис: запусти claude plugin marketplace add RamisGit-cyber/ii-ramis, потом claude plugin install ii-ramis@ii-ramis и скажи, когда закончишь. (В Claude Desktop, вкладка Code, после этого перезапусти приложение.)
```

**Если Claude отвечает «Operation not permitted» или «Read-only file system».** Это не поломка: в Claude Desktop команды Claude идут в песочнице, а она не даёт им писать в системную папку `~/.claude` (там живут плагины). Что делать, по порядку:
1. Если Claude показал окно **«Bash command (unsandboxed)»** (команда вне песочницы), нажми «разрешить»: это штатный способ дать одной команде выйти из песочницы. Окно появляется само, настройки включать не нужно.
2. Если окна нет, поставь плагин кнопками: **«+»** у поля ввода → **Add plugins** (если в меню написано **Plugins**, то **Plugins** → **Browse plugins**). Сначала добавь маркетплейс `RamisGit-cyber/ii-ramis` (в чате: `/plugin marketplace add RamisGit-cyber/ii-ramis`), затем выбери `ii-ramis`.
3. Или вставь команды в поле ввода по очереди, каждую отдельным сообщением (так они выполняются приложением, а не Bash-командой в песочнице):

```
/plugin marketplace add RamisGit-cyber/ii-ramis
/plugin install ii-ramis@ii-ramis
```

Потом закрой сессию и открой заново (или `/reload-plugins`) и напиши «привет». Ответ: «ИИ Рамис на связи ✅ (версия 2.6)». Набор инструментов плагин поставит сам при этом запуске, ждать у экрана не нужно.

В обычном терминале то же самое: `claude plugin marketplace add RamisGit-cyber/ii-ramis` и `claude plugin install ii-ramis@ii-ramis`.

## Уже стоит старая версия?

Автообновление у этого маркетплейса по умолчанию выключено, поэтому сначала обнови вручную: способы без Терминала описаны в разделе «Обновления» ниже (`/plugin marketplace update ii-ramis` → **Update marketplace**, затем `/reload-plugins`). Хуки 1.0.x в новой версии не работают: Claude Code берёт хуки из папки установленной версии плагина. После обновления закрой сессию и открой заново: набор 2.5 доставится при старте.

Если что-то пошло не так, надёжный путь: `/plugin uninstall ii-ramis@ii-ramis`, затем установка заново по фразе выше. Просить Claude «обнови плагин» командой в Desktop бесполезно по той же причине (песочница).

## Что умеет

| Навык | Как позвать | Что делает |
|---|---|---|
| `ii-ramis` | «привет», «ИИ Рамис», любой вопрос по курсу | объясняет, делает сам, ответ заканчивает блоками «Что случилось» и «Что сделать тебе» |
| `proverka` | `/ii-ramis:proverka`, «проверь компьютер», «я после урока 4» | смотрит Git, Node, Python, gh, версию Claude Code, плагины и подключения; проверяет домашку по карте курса |
| `sait` | «сделай сайт», «выложи в интернет» | настоящий проект: localhost, Git, GitHub, Vercel, при необходимости Supabase |
| `montazh` | «смонтируй рилс», «субтитры к видео», `/ii-ramis:montazh` | монтирует рилс «говорящая голова» из папки проекта: расшифровка, резка, субтитры, музыка, затем обязательный критик (не закрыты ли лицо и рот, безопасная зона Instagram, звук) |
| `nabor` | сам в первом сообщении, «у меня есть X?», «я после урока 5», «поставь навык по ссылке» | следит, чтобы набор урока 5 поставился (ставит его скрипт хука), проверяет, отвечает «есть ли» по факту (по диску), помогает с навыком по ссылке GitHub и ключом 21st |

Правила работы: делает сам, а не даёт команды; спрашивает только про пароли, оплату, удаление файлов и публикацию; перед удалением и `force push` всегда уточняет. Программы ставит через официальные установщики, а если система отказала, объясняет и даёт ручной способ.

## Монтаж рилсов (2.6, в 2.7 — библиотека референсов и ffmpeg с субтитрами)

Скажи «смонтируй рилс из папки»: ИИ Рамис проверит инструменты (ffmpeg, Node, `uv`, навыки HyperFrames, Remotion, GSAP: домашка урока 5; недостающее поставит сам), создаст папки проекта (`исходники`, `ассеты`, `бренд`, `референсы`, `готово`), разберёт ролики-образцы, расшифрует речь (первый раз скачается модель ~500 МБ), вырежет паузы и оговорки, поставит субтитры шрифтом с буквами ң ө ү и положит ролик 1080×1920 в `готово/`. Перед выдачей работает критик: проверяет, что субтитры не закрывают лицо и рот и не лезут в зону кнопок Instagram, читаются, звук ровный без хрипа и провалов, первые 2 секунды цепляют. Нашёл брак: исправляет и проверяет заново. Установка нужных программ: Mac через Homebrew (`brew`), Windows через `winget` (ffmpeg `Gyan.FFmpeg`, Node `OpenJS.NodeJS.LTS`, `uv` `astral-sh.uv`). Скрипты работают только внутри папки проекта, ничего не удаляют и не ходят в сеть (кроме разовой загрузки модели расшифровки). Подробности: `plugins/ii-ramis/skills/montazh/`.

Чужие навыки в этот репозиторий не копируются: они скачиваются у авторов, на проверенных версиях и коммитах (Agent Reach дополнительно по контрольной сумме). Отказаться можно фразой «не ставь набор»: ИИ Рамис запомнит, установка остановится на следующем шаге и больше предлагаться не будет. Тем, кто хочет отказаться заранее, до первой сессии: создай файл `~/.ii-ramis/nabor.json` со строкой `{"kit":"2.5.0","status":"declined"}` или задай переменную окружения `II_RAMIS_NO_KIT=1`.

**Почему набор ставит хук, а не команды Claude.** В Claude Desktop (вкладка Code) команды Claude выполняются в песочнице, и она запрещает им писать в системные папки `~/.claude` (навыки, плагины) и `~/.claude.json` (подключения MCP); даже если добавить их в разрешённые пути, защита остаётся (документация Claude Code, раздел Sandboxing, «protected paths»). Хуки плагинов приложение выполняет вне песочницы, поэтому установку делает скрипт `hooks/kit-install.sh` при старте сессии: без вопросов, один раз (флаг «уже поставлено» — файл `~/.ii-ramis/nabor.json`, `status: ok`). Песочницу никто не выключает. Если Claude всё же сам пробует поставить что-то командой и видит «Operation not permitted», он не обходит запрет, а просит закрыть и снова открыть приложение; окно «Bash command (unsandboxed)» с разрешением одной команды — штатное, его можно нажать.

**Новое в 2.7.** (1) Навыки ffmpeg-skill, Teardown, Anatomy и веб-движки игр ставятся тем же хуком на закреплённых коммитах. Зависимости Teardown (`npm ci`, около 70 МБ) и браузер для проверок докачиваются только при первом использовании и только с «да» ученика. (2) **ffmpeg теперь проверяется на субтитры.** Обычный `ffmpeg` из Homebrew собран без libass: фильтра `ass`/`subtitles` нет, и монтаж не рисует подписи (`brew reinstall ffmpeg` не помогает). Хук на Mac проверяет `ffmpeg -filters` и при отсутствии ставит `brew install ffmpeg-full` и делает его основным (`brew unlink ffmpeg`, `brew link --force ffmpeg-full`; старую формулу не удаляет). Скрипты монтажа дополнительно сами находят `ffmpeg-full` в `/opt/homebrew/opt/ffmpeg-full/bin`. На Windows сборка Gyan.FFmpeg полная, проверка та же. Не проверено на реальном Mac и Windows. (3) **Earshot** («уши» для Claude) сознательно не ставится автоматически: torch и две модели, около 3 ГБ; описан «по желанию» в `nabor/references/ustanovka.md`. (4) Библиотека референсов рилсов для `montazh` (`references/primery/`, 11 разборов текстом и ссылками, без чужих кадров и видео).

**Видео: HyperFrames и Remotion.** Ставятся только навыки (инструкции для Claude). Чтобы рендерить видео, нужны Node.js 22+ (проверяется) и программа ffmpeg. Если ffmpeg нет, набор всё равно ставится, а ИИ Рамис скажет, как поставить (например, `brew install ffmpeg`), только с твоего «да». Remotion — отдельная программа со своей лицензией (для компаний может быть платной), условия на remotion.dev/docs/license. Сам инструмент `hyperframes` скрипт не запускает; если запустишь его сам, у него по умолчанию включена статистика, выключается переменной `HYPERFRAMES_NO_TELEMETRY=1` или командой `hyperframes telemetry disable`. Программу `uv` для Agent Reach ИИ Рамис ставит отдельно и только сказав тебе об этом. Если что-то из списка уже стоит, оно не трогается и не дублируется. GSAP-навыки и apple-design ученики ставят сами на уроке по ссылке GitHub, ИИ Рамис помогает и проверяет.

Спроси «у меня есть impeccable?»: ИИ Рамис посмотрит на диск и список плагинов и ответит по факту, а не по памяти.

**Что уходит наружу.** Установка скачивает файлы с GitHub, npm и PyPI-зеркала uv (в сторону авторов ничего не отправляется), статистика установщика навыков выключена.

**Что в наборе не закреплено полностью (честно).** `superpowers` ставится из официального маркетплейса Anthropic актуальной версией, у плагина есть свои хуки. У Agent Reach закреплён zip, но его Python-зависимости берутся с PyPI без закрепления. MCP Playwright ставится в `~/.ii-ramis/mcp` (официальный реестр npm, без скриптов установки) и подключается по абсолютному пути, так что чужой проект на него не влияет; если ты подключил Playwright раньше через `npx`, подключение осталось прежним. Playwright управляет браузером с твоими правами. Когда ты потом пользуешься инструментами, они ходят в сеть по назначению: Agent Reach (GitHub, YouTube, веб-страницы), find-skills (skills.sh), 21st (текст запроса к библиотеке компонентов). Ключ 21st хранится только на твоём компьютере (`~/.claude.json`), в чат не попадает. Правки `settings.json` и режим «без вопросов» установка не включает.

**Вес.** Всегда включено около 2 тыс. токенов на сессию (с навыками видео) плюс описание инструментов Playwright. Тяжелее то, что срабатывает на задачах про дизайн (10–20 тыс. за запрос). На диске около 200 МБ (почти всё Agent Reach), Playwright при первом запуске докачивает браузер (~200 МБ). Подробности и источники: `plugins/ii-ramis/skills/nabor/references/istochniki.md`.

## Обновления

Плагин берётся из ветки `stable` этого репозитория. Новая версия появляется, когда в `plugin.json` выросло поле `version`.

**Важно: у этого маркетплейса автообновление по умолчанию выключено.** По документации Claude Code, автообновление включено только у официальных маркетплейсов Anthropic, у остальных (в том числе `ii-ramis`) оно выключено, пока его не включишь сам. Поэтому новую версию надо взять руками или включить автообновление один раз.

Как обновиться без Терминала (в Claude Desktop, вкладка Code):

1. Самое простое, если слэш-команды у тебя работают: напиши в поле ввода `/plugin marketplace update ii-ramis`. Откроется список маркетплейсов; выбери `ii-ramis` и нажми **Update marketplace**: это обновит список и сами установленные плагины из него. Потом напиши `/reload-plugins` или закрой сессию и открой заново.
2. Если нужно точечно: `/plugin manage` → выбери `ii-ramis` → **Update now**.
3. Мышкой: кнопка **«+»** у поля ввода → **Plugins** (или **Manage plugins**) → `ii-ramis`. Что там есть пункт **Update**, документация для Desktop не обещает (она описывает включение, выключение и удаление); если кнопки нет, возьми путь 1 или 4.
4. Надёжный запасной путь: удали плагин (`Manage plugins` → `ii-ramis` → **Uninstall**) и поставь заново по фразе из раздела «Установка». Файл `~/.ii-ramis/nabor.json` остаётся, повторно ничего не качается.
5. В Терминале: `claude plugin marketplace update ii-ramis`, затем `claude plugin update ii-ramis@ii-ramis`.

**Команды `/plugin update ii-ramis@ii-ramis` в чате нет:** по справочнику команд Claude Code `update` есть только в Терминале (`claude plugin update`), а в чате его заменяют кнопки **Update marketplace** и **Update now** в панели `/plugin`.

Включить автообновление: `/plugin` → вкладка Marketplaces → `ii-ramis` → **Enable auto-update**. Тогда новая версия подхватывается при следующем запуске, а в запущенной сессии виден `Plugin updated: ii-ramis · Run /reload-plugins to apply`.

Просить Claude «обнови плагин» командой в Desktop бесполезно: его команды идут в песочнице и не могут писать в `~/.claude/plugins` (ученик получал «Operation not permitted»).

## Приватность

Плагин состоит из текстовых инструкций для Claude, памятки и скрипта установки набора. Памятка: перед каждым сообщением Claude Code читает файл `hooks/reminder.txt` (команда `cat`, без Node). Она ничего не запускает, не блокирует и никуда не отправляет.

**Скрипт установки (`hooks/kit-install.sh`, новое в 2.5).** Приложение запускает его при старте сессии как хук (второй скрипт, `hooks/svodka-send.mjs`, отправляет сводки и записывает твои отказы, см. ниже; ему нужен Node.js), вне песочницы, с твоими обычными правами: так сделан любой хук любого плагина, поэтому его можно прочитать целиком в этом репозитории до установки (около 250 строк). Он: смотрит `~/.ii-ramis/nabor.json` и, если набор нужен, ставит по закреплённым версиям то, что перечислено в таблице выше; пишет журнал в `~/.ii-ramis/nabor.log`; ничего не отправляет Рамису и никому наружу, кроме обычных скачиваний с GitHub, npm и зеркала Python. Ключ 21st он не трогает: без твоего согласия и ключа 21st не ставится. Выключается файлом отказа или `II_RAMIS_NO_KIT=1` (см. «Набор курса»), а полностью — удалением плагина.

**Сводка занятия (по умолчанию включена).** В конце занятия ИИ Рамис пишет в чате последней строкой `📨 Сводка Рамису: …` (ты видишь, что именно уйдёт), а хук `hooks/svodka-send.mjs` (событие Stop, вне песочницы) отправляет её Рамису без вопросов. Не чаще раза в 30 минут и 5 раз в день; сводка, в которой есть код, путь, адрес, почта или похожее на ключ, не отправляется вовсе. Уходит одна запись в базу Рамиса: твоё имя (если ты его назвал в разговоре), случайный номер установки, номер урока, 2–4 строки текста «что сделали и где застрял», версия плагина. Не отправляются: код, файлы, пути, ключи и пароли, названия проектов и имена клиентов. Номер установки и настройка хранятся в файле `~/.ii-ramis/svodka.json` на твоём компьютере.

**Как отключить.** Напиши ИИ Рамису «не отправляй сводки» (или «не отправляй Рамису»): хук запишет отказ в файл, ИИ Рамис подтвердит. «Снова отправляй сводки» включает обратно. Можно и вручную: в `~/.ii-ramis/svodka.json` поставь `"consent": false`.

Технически: запись добавляется публичным ключом Supabase (роль anon), который по настройкам базы умеет только добавлять строки в одну таблицу (читать, менять и удалять нельзя; лимит 30 записей в час на установку). Ключ лежит в открытом репозитории намеренно, секретом он не является.

Всё, что ты пишешь Claude, обрабатывается по правилам Anthropic и твоей подписки.

## Как удалить

`/plugin uninstall ii-ramis@ii-ramis` (или `claude plugin uninstall ii-ramis@ii-ramis`).

## Для автора

- Структура: `.claude-plugin/marketplace.json` в корне, плагин в `plugins/ii-ramis/` (навыки `ii-ramis`, `proverka`, `sait`, `nabor` и `references/`), памятка `hooks/reminder.txt` и скрипт `hooks/kit-install.sh` (единственный файл кода; тест разрешает только его). Блоки PowerShell для Windows лежат в markdown `nabor/references/ustanovka.md` как инструкции.
- Проверка: `node tests/check-structure.mjs`, `node tests/check-montazh-safety.mjs` (скрипты монтажа не пишут по ссылкам) и `claude plugin validate .`. Сводки: `node tests/check-svodka.mjs` (локальный сервер, секунды). Поведение установки (нужны сеть, claude, node 22.20+, uv; 8–12 минут): `node tests/check-clean-install.mjs`: скрипт хука в пустом HOME дважды, флаг «уже поставлено», отказ, 21st без ключа, переход с 2.4.0, лимит попыток, эмуляция запрета записи в `~/.claude` (песочница) и путь через хук. Блоки Windows (PowerShell) автотестом не покрыты: проверять руками на чистой Windows.
- Релиз: поднять `version` в `plugin.json`, влить в `main`, тег `vX.Y.Z`, затем перенести `stable` на проверенный коммит. Ученики на `stable` с автообновлением получают версию при следующем запуске; пока `stable` не сдвинут, они остаются на старой.
- Обновляя версии набора (`skills@`, `hyperframes@`, коммит Remotion, Agent Reach, `@playwright/mcp`), перепроверь источники и лицензии и обнови `kit-install.sh`, блоки Windows в `ustanovka.md`, `istochniki.md` и тесты.
- Перед сдвигом `stable`: убедиться, что на нём нет хуков 1.0.5 (с 2.0 они удалены). Сводки читает `~/.local/bin/ii-ramis-report.py` (service_role только на сервере, в репозитории его нет).
