# ИИ Рамис — наставник для учеников курса «ИИнутый»

ИИ Рамис — это ИИ-помощник Рамиса Жолдошева, автора курса. Он живёт внутри Claude Code (вкладка Code в приложении Claude Desktop или команда `claude`): объясняет по-человечески, сам ставит и чинит всё нужное, проверяет компьютер и домашку, помогает собрать сайт. В конце каждого ответа два коротких блока: «🗣 Что случилось» и «🙋 Что сделать тебе».

Версия 2.4 — это набор навыков (скиллов) и одна памятка: перед каждым сообщением Claude читает короткий текст «ты ИИ Рамис, отвечай вот так». Памятка ничего не запускает, не блокирует и никуда не отправляет. Скриптов в плагине нет. Новое в 2.4: навык `nabor` сам ставит инструменты урока 5 (см. «Набор курса»). Короткая сводка занятия уходит Рамису по умолчанию, отключается одной фразой (см. «Приватность»).

> Идея и часть подхода: [vibe-coding-mentor](https://github.com/AzamatRaimbekov/vibe-coding-mentor) Азамата Раймбекова, лицензия MIT. См. `NOTICE.md`.

## Установка

Нужно: macOS или Windows, приложение Claude Desktop (claude.ai/download), подписка Claude Pro. Открой вкладку **Code**, выбери любую папку и вставь в чат эту фразу:

```
Установи плагин ИИ Рамис: запусти claude plugin marketplace add RamisGit-cyber/ii-ramis, потом claude plugin install ii-ramis@ii-ramis и скажи, когда закончишь. (В Claude Desktop, вкладка Code, после этого перезапусти приложение.)
```

Если Claude не может выполнить слэш-команды сам, вставь их по очереди в поле ввода (каждую отдельным сообщением):

```
/plugin marketplace add RamisGit-cyber/ii-ramis
/plugin install ii-ramis@ii-ramis
```

Потом закрой сессию и открой заново (или `/reload-plugins`) и напиши «привет». Ответ: «ИИ Рамис на связи ✅ (версия 2.4)».

В обычном терминале то же самое: `claude plugin marketplace add RamisGit-cyber/ii-ramis` и `claude plugin install ii-ramis@ii-ramis`.

## Уже стоит старая версия (1.0.x)?

Если включено автообновление (по умолчанию так и есть), новая версия подтянется сама при следующем запуске Claude Code, когда автор её выпустит. Если автообновление ты выключал, вставь в чат Claude Code:

```
Обнови плагин ИИ Рамис до последней версии: запусти claude plugin marketplace update ii-ramis, потом claude plugin update ii-ramis@ii-ramis и скажи, когда закончишь. Потом перезапусти Claude. В Claude Desktop можно и мышкой: кнопка «+» у поля ввода → Manage plugins → ii-ramis → Update.
```

Слэш-команды `/plugin` старая защита не блокирует: она проверяла только вызовы инструментов, а не команды плагинов. После обновления закрой сессию и открой заново. Хуки 1.0.x в новой версии не работают: Claude Code берёт хуки из папки установленной версии плагина, а в 2.0 их нет.

Если что-то пошло не так, надёжный путь: `/plugin uninstall ii-ramis@ii-ramis`, затем установка заново по фразе выше.

## Что умеет

| Навык | Как позвать | Что делает |
|---|---|---|
| `ii-ramis` | «привет», «ИИ Рамис», любой вопрос по курсу | объясняет, делает сам, ответ заканчивает блоками «Что случилось» и «Что сделать тебе» |
| `proverka` | `/ii-ramis:proverka`, «проверь компьютер», «я после урока 4» | смотрит Git, Node, Python, gh, версию Claude Code, плагины и подключения; проверяет домашку по карте курса |
| `sait` | «сделай сайт», «выложи в интернет» | настоящий проект: localhost, Git, GitHub, Vercel, при необходимости Supabase |
| `nabor` | сам в первом сообщении, «у меня есть X?», «я после урока 5», «поставь навык по ссылке» | ставит и проверяет набор урока 5, отвечает «есть ли» по факту (по диску), помогает с навыком по ссылке GitHub и ключом 21st |

Правила работы: делает сам, а не даёт команды; спрашивает только про пароли, оплату, удаление файлов и публикацию; перед удалением и `force push` всегда уточняет. Программы ставит через официальные установщики, а если система отказала, объясняет и даёт ручной способ.

## Набор курса (урок 5, версия 2.4)

Чтобы на уроке никто ничего не устанавливал, при первом сообщении после обновления ИИ Рамис сам ставит инструменты и говорит об этом одной строкой (1–3 минуты, один раз):

| Что | Откуда | Лицензия | Ключ |
|---|---|---|---|
| find-skills | vercel-labs/skills | MIT | нет |
| impeccable (только навык, без хуков) | pbakaus/impeccable | Apache-2.0 | нет |
| emil-design-eng | emilkowalski/skills | MIT | нет |
| agent-reach (каналы без входа) | Panniantong/Agent-Reach v1.6.1 | MIT | нет |
| superpowers | obra/superpowers через `claude-plugins-official` | MIT | нет |
| humanizer (как навык) | blader/humanizer | MIT | нет |
| Playwright MCP | npm `@playwright/mcp@0.0.84` | Apache-2.0 | нет |
| 21st Magic MCP | 21st.dev, github.com/21st-dev/magic-mcp | ISC | **личный ключ**, ставится только с согласия ученика |

Чужие навыки в этот репозиторий не копируются: они скачиваются у авторов, на проверенных коммитах (Agent Reach дополнительно по контрольной сумме). Отказаться можно фразой «не ставь набор»: ИИ Рамис запомнит и не будет предлагать. Программу `uv` для Agent Reach ИИ Рамис ставит отдельно и только сказав тебе об этом. Если что-то из списка уже стоит, оно не трогается и не дублируется. GSAP-навыки и apple-design ученики ставят сами на уроке по ссылке GitHub, ИИ Рамис помогает и проверяет.

Спроси «у меня есть impeccable?»: ИИ Рамис посмотрит на диск и список плагинов и ответит по факту, а не по памяти.

**Что уходит наружу.** Установка скачивает файлы с GitHub, npm и PyPI-зеркала uv (в сторону авторов ничего не отправляется), статистика установщика навыков выключена. Когда ты потом пользуешься инструментами, они ходят в сеть по назначению: Agent Reach (GitHub, YouTube, веб-страницы), find-skills (skills.sh), 21st (текст запроса к библиотеке компонентов). Ключ 21st хранится только на твоём компьютере (`~/.claude.json`), в чат не попадает. Правки `settings.json` и режим «без вопросов» установка не включает.

**Вес.** Всегда включено около 1,2 тыс. токенов на сессию плюс описание инструментов Playwright. Тяжелее то, что срабатывает на задачах про дизайн (10–20 тыс. за запрос). На диске около 180 МБ (почти всё Agent Reach), Playwright при первом запуске докачивает браузер (~200 МБ). Подробности и источники: `plugins/ii-ramis/skills/nabor/references/istochniki.md`.

## Обновления

Плагин следит за веткой `stable` этого репозитория. Новая версия подхватывается, когда в `plugin.json` выросло поле `version`. Вручную: `/plugin marketplace update ii-ramis`, затем `/plugin update ii-ramis@ii-ramis`, потом перезапуск. Отключить автообновление: `/plugin` → вкладка Marketplaces → `ii-ramis` → Disable auto-update.

## Приватность

Плагин состоит из текстовых инструкций для Claude (в том числе команд установки набора, которые Claude запускает сам и показывает ученику) и одной памятки: перед каждым сообщением Claude Code читает файл `hooks/reminder.txt` (команда `cat`, без Node). Она ничего не запускает, не блокирует и никуда не отправляет.

**Сводка занятия (по умолчанию включена).** В конце занятия ИИ Рамис молча отправляет Рамису короткую сводку, без вопросов. Уходит одна запись в базу Рамиса: твоё имя (если ты его назвал в разговоре), случайный номер установки, номер урока, 2–4 строки текста «что сделали и где застрял», версия плагина. Не отправляются: код, файлы, пути, ключи и пароли, названия проектов и имена клиентов. Номер установки и настройка хранятся в файле `~/.ii-ramis/svodka.json` на твоём компьютере.

**Как отключить.** Напиши ИИ Рамису «не отправляй сводки» (или «не отправляй Рамису»): он запишет отказ в файл и подтвердит. Можно и вручную: в `~/.ii-ramis/svodka.json` поставь `"consent": false`.

Технически: запись добавляется публичным ключом Supabase (роль anon), который по настройкам базы умеет только добавлять строки в одну таблицу (читать, менять и удалять нельзя; лимит 30 записей в час на установку). Ключ лежит в открытом репозитории намеренно, секретом он не является.

Всё, что ты пишешь Claude, обрабатывается по правилам Anthropic и твоей подписки.

## Как удалить

`/plugin uninstall ii-ramis@ii-ramis` (или `claude plugin uninstall ii-ramis@ii-ramis`).

## Для автора

- Структура: `.claude-plugin/marketplace.json` в корне, плагин в `plugins/ii-ramis/` (навыки `ii-ramis`, `proverka`, `sait`, `nabor` и `references/`), памятка `hooks/reminder.txt`. Файлов кода в плагине нет (команды установки лежат в markdown `nabor/references/ustanovka.md` как инструкции); тест разрешает только этот хук.
- Проверка: `node tests/check-structure.mjs` и `claude plugin validate .`. Чистая установка набора (нужны сеть, claude, node 22.20+, uv; 1–3 минуты): `node tests/check-clean-install.mjs`, запускает блоки установки в пустом HOME дважды. Блоки Windows (PowerShell) автотестом не покрыты: проверять руками на чистой Windows.
- Релиз: поднять `version` в `plugin.json`, влить в `main`, тег `vX.Y.Z`, затем перенести `stable` на проверенный коммит. Ученики на `stable` с автообновлением получают версию при следующем запуске; пока `stable` не сдвинут, они остаются на старой.
- Обновляя версии набора (`skills@`, Agent Reach, `@playwright/mcp`), перепроверь источники и лицензии и обнови `istochniki.md`, `ustanovka.md` и `check-clean-install.mjs`.
- Перед сдвигом `stable`: убедиться, что на нём нет хуков 1.0.5 (с 2.0 они удалены). Сводки читает `~/.local/bin/ii-ramis-report.py` (service_role только на сервере, в репозитории его нет).
