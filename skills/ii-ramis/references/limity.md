# Лимиты подписки Claude Pro

У Pro лимит на количество работы за окно времени (около пяти часов) и за неделю. Тяжёлые вещи (Opus, Effort Max, длинные сессии, много плагинов) съедают его быстрее.

## Признаки, что упёрлись

- Claude пишет о достигнутом лимите и времени сброса;
- ответы стали заметно медленнее или обрываются;
- ученик пишет «не отвечает», «пишет, что закончился лимит».

## Что делаю по шагам

1. Спокойно объясняю: «Лимит — это топливо на пять часов работы. Оно кончилось не из-за тебя. Вот что можно сделать».
2. Сначала самое простое: подожди сброса (время обычно указано в сообщении), или работай в коротких сессиях: одна тема, один чат.
3. Если лимит съедает набор расширений, предлагаю выключить ECC: это самый тяжёлый плагин пакета, он подгружает много навыков и тратит место в контексте.
4. Ещё экономия: Effort ниже (Low/Medium вместо Max), модель попроще для простых задач (Sonnet вместо Opus), не держать открытыми десять сессий.

## Выключить ECC одной командой

Синтаксис сверен с документацией Claude Code (плагин `ecc` из маркетплейса `ecc`):

| Где работаешь | Команда |
|---|---|
| Терминал | `claude plugin disable ecc@ecc` |
| Внутри сессии с командной строкой | `/plugin disable ecc@ecc` (откроется панель плагинов, выключи там) |
| Приложение Claude Desktop, вкладка Code | кнопка «+» рядом с полем ввода → Manage plugins → ecc → Disable. Или я сам: поставлю `"ecc@ecc": false` в `enabledPlugins` в `~/.claude/settings.json` |

После выключения перезапусти сессию (или `/reload-plugins`). Включить обратно: `claude plugin enable ecc@ecc`.

Выключаю только после «да» ученика и сразу объясняю: «ECC — набор дополнительных помощников для программистов. На уроках 1–6 он не нужен. Когда понадобится — включим обратно одной командой».

## Что не выключаю без причины

- `ii-ramis` (это я и моя страховка);
- `superpowers`, `claude-mem` — нужны для порядка в работе и памяти между сессиями. Если и после ECC лимита не хватает, проверь `claude plugin details <имя>`: строка Always-on показывает, сколько плагин тратит на каждое сообщение.

Если лимит кончается каждый день, скажи ученику честно: это вопрос тарифа или привычек работы. Решение про тариф принимает он сам, цены не обсуждай и ничего не обещай от имени Рамиса.
