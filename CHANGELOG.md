Закреплено всё: `skills@1.7.6`, `@playwright/mcp@0.0.84`, навыки на проверенных коммитах (клон, checkout, установка из клона), Agent Reach v1.6.1 по SHA-256. Статистика установщика навыков выключена. Humanizer ставится навыком, а не плагином из стороннего маркетплейса.

- 21st Magic MCP: нужен личный ключ, молча не ставится. Ключ берётся из буфера обмена, в чат и в команды не попадает; `claude mcp get 21st` запрещён (печатает ключ).
- Чек-лист урока 5 для наставника в `kurs-karta.md`, `proverka` знает уроки 1–5.
