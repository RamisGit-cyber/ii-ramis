# Изменения

## 2.7.0 (06.11.2026) — новые навыки в набор, ffmpeg с субтитрами, библиотека референсов
- **Монтаж в режиме «Про» (главное в 2.7).** `montazh` теперь по умолчанию (если стоит HyperFrames и Node 22+) собирает рилс как HyperFrames-композицию: подложка с вырезанными паузами, анимированные субтитры по словам с плашкой на ключевом слове, моушн-вставки по смыслу каждые 2–3 секунды, зум-акценты, музыка и звуки, рендер HyperFrames и тот же обязательный критик. Навык комбинирует то, что есть у ученика: `hyperframes*`, `emil-design-eng`, `apple-design`, `animate`, `animation-vocabulary`, GSAP, `find-animation-opportunities`, `improve-animations`, `anatomy`, `teardown`, его материалы (скрины, логотипы, «второй мозг»; за пределами папки проекта только по «да» ученика) и библиотеку референсов. Методика и проверенный рецепт (сцена 11 с на сервере: рендер ~1,5 минуты на один поток, кадры просмотрены глазами) в `montazh/references/pro.md`. Базовый режим на ffmpeg остался запасным.
- В набор добавлены навыки анимации из emilkowalski/skills на том же коммите `f1090be` (MIT): `apple-design`, `animate`, `animation-vocabulary`, `find-animation-opportunities`, `improve-animations`. Закрепление навыков HyperFrames обновлено на тег v0.9.19 (`b4cc674`), под него проверен рецепт; версия CLI в рецепте `hyperframes@0.9.19`.
- Музыкальная библиотека для `montazh` (`montazh/assets/`): 12 треков Kevin MacLeod (CC BY 4.0, атрибуция обязательна, текст в `LICENSES.md`, навык напоминает ученику вставить её в описание ролика) и 26 коротких звуков CC0 (Kenney и собственный синтез). Вес 16 МБ.
- **Earshot: плагин предлагает сам, ставит только по «да».** После проверки набора (и в шаге 0 монтажа) ИИ Рамис один раз предлагает Earshot («~3 ГБ и минут 10»), «да» запускает `kit-install.sh --earshot` (закреплены коммит `591fa3e`, `torch==2.14.1`, `mcp==2.3.0`; Windows: блок PowerShell), отказ «не ставь Earshot» записывает хук в `~/.ii-ramis/earshot-declined`. Хук запуска и `--run` Earshot не ставят.
- Режим «Про»: пустых карточек не бывает (вставка сразу с содержимым или без неё), критик проверяет пункт «нет пустых карточек».
- **Субтитры на Mac.** Обычный `ffmpeg` из Homebrew теперь собран без libass: фильтров `ass` и `subtitles` нет, и монтаж не рисует субтитры; `brew reinstall ffmpeg` не помогает. Теперь хук установки на Mac проверяет `ffmpeg -hide_banner -filters`, и если фильтра нет, ставит `brew install ffmpeg-full` и делает его основным (`brew unlink ffmpeg` + `brew link --force ffmpeg-full`; при неудаче ссылка на старый `ffmpeg` возвращается, старая формула не удаляется). Скрипты `montazh` сами находят `ffmpeg-full` в `/opt/homebrew/opt/ffmpeg-full/bin` и `/usr/local/opt/ffmpeg-full/bin`, а если полной сборки нет, останавливаются с понятным текстом. Шаг 0 монтажа и `ustanovka.md` проверяют не только наличие ffmpeg, но и фильтр; Windows (Gyan.FFmpeg, полная сборка) проверяется тем же тестом. В `notes` появились `ffmpegsubs` и `python`. Таймаут асинхронного хука 900 → 1800 с (ffmpeg-full тянет много зависимостей). **Не проверено на реальном Mac и Windows** (проверено на Linux и тестами), поэтому после обновления на Mac стоит посмотреть вывод `ffmpeg -filters`.
- **В набор добавлены (закреплённые коммиты, клон без символических ссылок, `skills@1.7.6`):** ffmpeg-skill v3.2.0 (`9bdb444`, MIT; установщик автора из клона, без сети и postinstall), Teardown (`a91262a`, MIT), Anatomy (`1482e84`, MIT; скрипт публикации `publish.mjs` с `git push` в чужую галерею перед установкой удаляется), веб-движки игр из awesome-gamedev-agent-skills (`19d93f9`, Apache-2.0): `router`, `phaser-core`, `phaser-arcade-physics`, `pixijs-rendering`, `threejs-scene-setup`, `threejs-gltf-loading`, `threejs-materials-lighting` (остальные 70 навыков не ставятся). У тех, у кого стоял 2.6, при старте допоставится только недостающее.
- Зависимости Teardown (three, esbuild, playwright; около 70 МБ) и браузер для проверок докачиваются при первом использовании и только с «да» ученика (`npm ci --ignore-scripts`), не хуком.
- **Earshot не ставится автоматически**: torch и две модели (~1,1 ГБ), ~3 ГБ на диске, 20–40 с на вызов. Раздел «Earshot по желанию» в `nabor/references/ustanovka.md` (закреплённый коммит `591fa3e`, окружение в `~/.ii-ramis/earshot`, MCP только с «да»). Glisse и Ghost Editor не ставятся (причины в `istochniki.md`).
- **Библиотека референсов для `montazh`** (`references/primery/`): README и 11 разборов ref-02…ref-12 (крючок, структура по секундам, приёмы монтажа, как повторить). Шаг 2 навыка: на «сделай как референс 09» или «нужны идеи» читать README и нужный файл. Только текст и ссылки, чужие кадры и видео не вложены и не скачиваются без просьбы ученика.
- Тесты: версия 2.7, десять наборов навыков, закрепление новых коммитов, проверка субтитров ffmpeg, удаление `publish.mjs`, brew только для `node` и `ffmpeg-full`.

## 2.5.0 (04.11.2026) — набор ставится даже в песочнице Claude Desktop

- **Что сломалось на уроке 5.** В Claude Desktop (вкладка Code) команды Claude идут в песочнице, и она не даёт им писать в системную папку `~/.claude` и в файл `~/.claude.json`. Ученики получали «Operation not permitted», набор не вставал. Это защита приложения, а не поломка, и добавить эти пути в разрешённые нельзя (документация Claude Code, раздел Sandboxing).
- **Как починено.** Набор теперь ставит скрипт `hooks/kit-install.sh`, который приложение запускает при старте сессии как хук. Хуки плагинов выполняются вне песочницы, так что запись в `~/.claude` проходит. Без вопросов, один раз: флаг «уже поставлено» — `~/.ii-ramis/nabor.json` (`status: ok`, `kit: 2.5.0`). Песочницу никто не выключает и не обходит.
- Отказ «не ставь набор» работает: установка останавливается на следующем шаге, уже поставленное не удаляется. Отключить можно и заранее: переменная `II_RAMIS_NO_KIT=1`.
- В набор добавлены **HyperFrames** (4 навыка HeyGen из клона на закреплённом коммите 1ff4cef = тег v0.9.12; собственный установщик HyperFrames не используется) и **Remotion** (13 навыков, коммит c7cb2fd). Нет Node 22.20+ или git — честно пишется, что не поставилось, остальное ставится. Нет ffmpeg — это заметка, а не ошибка: ИИ Рамис скажет, как поставить, только с «да» ученика.
- По итогам ревью безопасности: `npx` запускается из временной папки и с официального реестра npm, поля `notes` и `missing` очищаются перед передачей Claude, лимит попыток действует и для оборванной установки, у асинхронного хука таймаут 900 с, скрипт работает только на Mac и Linux, закрытые права файлов (`umask 077`), у клона отключены подмодули и протокол file. README честно перечисляет, что закреплено не полностью.
- Playwright MCP ставится в `~/.ii-ramis/mcp` (`npm install --prefix`, официальный реестр, без пользовательского `.npmrc`, без скриптов) и подключается по абсолютному пути, а не через `npx` из папки проекта (замечание автоматической проверки).
- 21st по-прежнему только с согласием и личным ключом ученика.
- Навык `nabor` переписан: ждёт результат хука, не ставит сам Bash-командами, на «Operation not permitted» не обходит запрет, а объясняет, что нажать (закрыть и открыть приложение; окно «Bash command (unsandboxed)» — штатное).
- README: путь обновления без Терминала и важная находка: **автообновление у стороннего маркетплейса по умолчанию выключено** (по документации), поэтому ученик сам берёт новую версию через `/plugin marketplace update ii-ramis` → Update marketplace или включает автообновление. Команды `/plugin update` в чате нет (она есть только в Терминале).
- Тесты: `tests/check-clean-install.mjs` переписан под скрипт хука (идемпотентность, флаг, отказ, 21st без ключа, переход с 2.4.0, лимит попыток, эмуляция запрета записи и путь через хук); `tests/check-structure.mjs` теперь разрешает ровно один скрипт.
- **Сводки Рамису снова доходят.** В 2.4 сводку слал Claude командой `curl` через Bash, а песочница Desktop режет сеть для доменов не из списка (команда ждёт окна разрешения или получает отказ) и запись вне рабочей папки, поэтому сводки молча терялись (ошибку правило велело скрывать). Теперь Claude пишет в чате строку `📨 Сводка Рамису: …`, а отправляет хук Stop `hooks/svodka-send.mjs` вне песочницы: только 2–4 строки до 400 символов, без кода, путей, адресов, почты и ключей (иначе не отправляется), раз в 30 минут и 5 раз в день, ключ anon только на INSERT, согласие по умолчанию включено. Отказы («не отправляй сводки», «не ставь набор» и обратные) записывает хук UserPromptSubmit: Bash в песочнице писать в `~/.ii-ramis` не может.
- Памятка и приветствие: версия 2.5.
