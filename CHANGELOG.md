# Изменения

## 2.9.1 (11.11.2026) — имя в сводках, «обнови плагин» без простыни
- **Имя ученика.** В сводках почти у всех было «без имени»: имя попадало в `~/.ii-ramis/svodka.json` только если Claude сам писал «имя: …» в строке сводки. Теперь, если имени нет (и ученик не отказался от сводок), хук `UserPromptSubmit` в первом сообщении сессии просит Claude один раз дружелюбно спросить «Как тебя зовут? Нужно, чтобы Рамис в сводках видел, кому помочь», а **ответ записывает сам хук** (следующее сообщение ученика; Claude файлов не пишет). Принимает «Айдана», «Меня зовут Айдана», «Я Айдана», «Имя: Айдана»; «привет», «сделай сайт», «Расскажи» и всё, что не похоже на имя, ответом не считается. Имя: только буквы, пробел и дефис, до 40 символов, не больше трёх слов (то же ограничение для «имя:» из строки сводки). Один вопрос за сессию, не больше трёх за всё время; «не скажу», «нет», «без имени» запоминается (`name_declined`) и больше не спрашивают, в том числе имя из строки сводки тогда не берётся. «Забудь моё имя» удаляет имя. При `consent: false` не спрашивают; служебные фразы («обнови…», «поставь…») вопросом не перебиваются. Само имя в контекст Claude хук не печатает.
- **«Обнови плагин ИИ Рамис» в Claude Desktop (баг из группы 11.11).** Хук не находил `claude`, и Claude выдавал ученику простыню с `/plugin` → Manage plugins. Теперь `find_claude` ищет в PATH, `~/.local/bin`, `~/.claude/local`, npm (`npm prefix -g`, `~/.npm-global`), nvm, Volta, Bun, Homebrew и во встроенных копиях Claude Desktop (Mac: `Application Support/Claude/claude-code` и `claude-code-vm`, Linux: `~/.config/Claude/claude-code`; по имени файла внутри папки версии, не по жёсткому пути). Если не нашёл, хук сравнивает версию установленного плагина с последней на GitHub и велит Claude сказать ровно одну строку: «Плагин уже последней версии X» / «Вышла новая версия Y, у тебя X. Полностью закрой приложение и открой заново; если версия не изменится, напиши в группу курса» / «Не получилось проверить новую версию…». Про `/plugin`, Manage plugins и команды ученику не пишется нигде (инструкции и блок PowerShell исправлены). Если `claude` найден, хук тоже сообщает последнюю версию на GitHub и при совпадении просит сказать «уже последней версии».
- Тесты: `check-svodka.mjs` (вопрос про имя один раз за сессию и не больше трёх раз, принимаемые и отвергаемые ответы, отказ, «забудь», consent false, служебные фразы), `check-update.mjs` (поиск `claude` по шести запасным путям, три ответа без `claude`, в строке для ученика нет `/plugin`). `KIT_VERSION` остаётся 2.9.0 (набор не менялся).

## 2.8.0 (07.11.2026) — Афиша один в один с Монтажкой
- **Афиша переделана по живому ролику Монтажки (Эрика, 13.10), а не по описанию.** Разбор показал, что «пародия» была от четырёх вещей: слово-фон было тонким и широким (Onest Light), а у Монтажки это тяжёлый узкий Druk Medium 330–400 px; строка и главное слово сидели близко ко рту без тонкой строки и без рукописного слова; всё появлялось целой табличкой за 0,1–0,3 с вместо проявления по словам и по буквам; маска MediaPipe давала мягкий неровный край.
- **Рендер через HyperFrames** (`scripts/afisha_hf.py`, вызывается из `montage.py build`, нужен Node 22+): два прозрачных слоя (слово-тема за человеком и таблички перед ним), GSAP, кегли, тайминги, цвета и позиции из эталона: слово-фон по буквам от центра за 0,3 с, зачёркивание красной полосой (`strike`), тонкая строка по словам на их времени (по расшифровке), главное слово с подъёмом 12 px за 0,13 с, рукописное −7° со свечением, наезд 1.0→1.04 (в соседнем куске 1.05→1.07), тихие удар и «вжух» из `assets/sfx`. HyperFrames нет или он не отрисовал: запасной путь на ASS (`layouts.py`) с теми же размерами и позициями. Критик понимает оба режима.
- **Маска RVM** (как у Монтажки; `segment.py`): onnxruntime 1.20.1 вместо MediaPipe (окружение с ~350 МБ стало ~60 МБ), модель 15 МБ скачивается `install_rvm.py` с официального GitHub-релиза авторов (v1.0.0, SHA256 закреплён) по «да» ученика и в плагин не входит. Лицензия RVM GPL-3.0 (код и веса), в плагине её нет; подробности и честная оговорка в `NOTICE.md`. Старое окружение MediaPipe продолжает работать как запасное.
- **Шрифты.** Платные Druk Cyr, Benzin и Denistina в репозиторий не входят: ученик пишет «поставь шрифты Афиши» и вставляет закрытую ссылку из группы курса, `install_fonts.py` качает архив (только https, до 3 МБ, без цифровых адресов, все переходы тоже https), сверяет SHA256 с хешем в плагине (`references/afisha-fonts.sha256`, сама ссылка не хранится), достаёт только 4 известных файла без папок и ссылок в `~/.ii-ramis/fonts` (Mac и Windows), ничего не запускает. Без них: свободные аналоги в репозитории (Fira Sans Extra Condensed Medium и ExtraBold, Rubik Mono One, Bad Script; все SIL OFL, есть ң ө ү).
- По ревью безопасности: адрес проверяется строже (отказ цифровым и сокращённым адресам вроде `2130706433`, `0x7f.1`, `127.1`, имён с точкой на конце и без зоны), общий срок загрузки 5 минут, распаковка во временный файл с заменой имени, SRI на скрипт GSAP, `npx` запускается из папки слоя, ссылки в рабочей папке Афиши отказывают, в JSON страницы экранируется `<!--`. Остаточный риск (цепочка npm у HyperFrames, хеши пакетов маски) записан в `NOTICE.md`.
- Ритм по эталону: 12–15 табличек на 24 с (фраза за фразой), слово-фон на 2–3 планах, не «3–5 громких слов».
- Тесты: версия 2.8.0, закрепление хеша и версий маски, безопасность загрузки и распаковки (отказ http, цифровых адресов, лишних файлов, `..`, не тот хеш).
