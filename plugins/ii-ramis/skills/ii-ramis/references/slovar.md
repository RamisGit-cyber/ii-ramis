# Словарь: термин → пример из жизни

Объясняй одним примером, не всем списком. Термин называй один раз, дальше живи своими словами ученика.

## Основные (из задания)

| Термин | Простыми словами |
|---|---|
| Фронтенд | Зал кафе: что видит гость (кнопки, тексты, картинки). |
| Бэкенд | Кухня: что гость не видит, но без этого еды не будет (проверка, обработка, хранение). |
| localhost | Репетиция дома: сайт работает только у тебя на компьютере, никто больше его не видит. |
| Хостинг | Аренда помещения: компьютер в интернете, на котором живёт твой сайт круглые сутки. |
| База данных | Тетрадь заказов: куда записываются заявки, пользователи, товары, чтобы ничего не потерялось. |
| API | Официант: ты (сайт) говоришь ему, что нужно, он несёт заказ на кухню и возвращает ответ. |
| Git | Сохранения в игре: можно вернуться к любой точке, если дальше всё сломалось. |
| GitHub | Облако для сохранений: твои сохранения лежат не только на ноутбуке. |
| .env | Сейф для ключей: пароли и ключи лежат в нём, а не на видном месте в коде. |
| Деплой | Открытие кафе для гостей: сайт переезжает с репетиции дома в интернет по ссылке. |
| Context7 | Свежая инструкция к инструментам: Claude читает актуальную документацию, а не вспоминает по памяти. |
| MCP | Переходник: «руки» Claude, через которые он работает с сервисами (браузер, почта, база). |

## Ещё частые

| Термин | Простыми словами |
|---|---|
| Коммит | Одно сохранение в игре с подписью «что я сделал». |
| Ветка | Черновик рядом с чистовиком: пробуешь новое, не портя рабочее. |
| Репозиторий | Папка проекта вместе со всеми её сохранениями. |
| Терминал | Окно, где с компьютером разговаривают командами вместо кнопок. Claude печатает команды сам. |
| Пакет (npm) | Готовая деталь от другого мастера: не изобретаешь колесо, берёшь готовое. |
| Node.js | Двигатель, на котором запускаются сайты и скрипты. |
| Переменная окружения | Записка на кухне: «сегодня соль в синей банке». Программа читает её, когда запускается. |
| Ключ API | Пропуск в сервис. Потеряешь или покажешь чужому — пользоваться будет он, а платить ты. |
| Anon-ключ (Supabase) | Пропуск для гостей: безопасно лежит на сайте, потому что гостю разрешено только то, что ты разрешил в правилах. |
| service_role ключ | Ключ от всех дверей кухни. Только в сейфе (.env), на сайт никогда. |
| RLS (правила строк) | Охранник у тетради: решает, кто что может записать и прочитать. |
| Домен | Адрес кафе на карте (mysite.kg), вместо «улица без названия» (случайная ссылка Vercel). |
| Ошибка 404 | «Такой страницы нет»: пришёл по адресу, а там пусто. |
| Ошибка 500 | «Сломалось на кухне»: гость сделал всё правильно, но сервер упал. |
| Ошибка 401/403 | «Тебя не пустили»: нет пропуска или он не тот. |
| Билд (сборка) | Упаковка блюда в коробку перед отправкой гостю. |
| Зависимости | Детали, без которых сайт не соберётся. Если «не найден модуль» — детали не докачали. |
| Playwright | Невидимый помощник с браузером: сам открывает сайт, нажимает кнопки и проверяет, что работает. |
| Скилл | Сохранённая инструкция для Claude: «когда просят X — делай вот так». |
| Хук | Автоматический сторож: срабатывает сам перед или после действия (например, остановит опасную команду). |
| Плагин | Коробка с навыками и сторожами, которую ставят одной командой. |
| Контекст | Рабочая память Claude: чем длиннее разговор, тем хуже он помнит начало. «Одна тема, один чат». |
| Токены / лимит | Топливо подписки: каждый ответ тратит, на сложные задачи уходит больше. |
