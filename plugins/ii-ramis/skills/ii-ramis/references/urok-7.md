# Урок 7: харнесы, безопасность, разработка по плану

Для наставника: объясняй короткими кусками, по запросу ученика. Ученику даёшь только фразы, не слеш-команды.

## Что такое харнес

Claude сам по себе умный, но работает «как получится». **Харнес** (в переводе «упряжь», «обвязка») — набор правил, навыков и помощников вокруг него, который заставляет работать по порядку: сначала понять задачу, составить план, потом писать код, потом проверить и только потом говорить «готово». Как рабочий процесс на заводе вокруг хорошего мастера.

Что у нас: **Superpowers** (порядок: идея → план → маленькие шаги → тесты → проверка) и **ECC** (много готовых навыков и помощников для разработки, безопасность, проверка кода). Ставятся фразами «поставь Superpowers», «поставь ECC», «поставь всё для урока 7» (навык `harnes`).

## Навык или агент: что выбрать

- **Навык (скилл)** — умение, которое Claude подключает **в том же разговоре**. Как книга с инструкцией: он её прочитал и действует дальше сам, с тем же контекстом (помнит всё, что вы обсуждали). Быстро, дёшево, но память общая и может «засориться».
- **Агент (субагент)** — **отдельный сотрудник со своим контекстом**: получает задание, работает в стороне, возвращает короткий итог. Основной разговор не засоряется, несколько агентов могут работать параллельно, а проверяющий агент смотрит свежим взглядом (не знает, как вы договаривались писать код). Но он не видит вашего разговора: всё нужное надо вложить в задание, и тратит он больше лимита.

Когда что:
| Ситуация | Берём |
|---|---|
| Нужно умение в текущей работе (дизайн по правилам, написать текст) | навык |
| Большая задача, которая забьёт разговор (разобрать весь проект, прочитать 50 файлов) | агент |
| Независимые куски (сайт и бот одновременно) | несколько агентов параллельно |
| Проверка «чужим глазом» (безопасность, ревью кода) | агент |
| Маленькая правка в одном файле | ни то ни другое, просто делаем |

Пример на пальцах: навык — «Claude открыл книгу по безопасности»; агент — «Claude позвал отдельного проверяющего, дал ему папку и сказал: найди дыры и коротко доложи».

## Безопасность (навык `bezopasnost`)

Фраза «проверь безопасность моего проекта»: ты проверяешь изменения и весь проект, объясняешь находки простыми словами, исправляешь и перепроверяешь. Глубокий аудит Cloudflare — по «да» (дорого по лимиту). Strix (ИИ-пентест) — только инструкция, только свой сайт, только по явному «да».

Главные правила для ученика, которые стоит произнести: ключ в код и в чат не кладём; `.env` не в git; у базы включён RLS; выкладываем сначала на preview; чужие сайты не проверяем.

## Разработка по плану

Большую фичу (больше часа) делай так: 1) цель простыми словами; 2) план из 3–7 шагов, ученик говорит «ок»; 3) что может сломаться (самокритика); 4) по шагу: сделал, проверил, показал; 5) отдельная ветка git, маленькие коммиты; 6) перед выкладкой — проверка безопасности и preview. Если Superpowers стоит, он сам ведёт по этому порядку.
