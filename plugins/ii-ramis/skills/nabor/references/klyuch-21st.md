# 21st.dev Magic (MCP): личный ключ, подключение без показа ключа

Проверено по документации 21st (github.com/21st-dev/magic-mcp, лицензия ISC; страница 21st.dev/mcp, 03.11.2026): **личный API-ключ нужен**. Его выдаёт аккаунт на 21st.dev (бесплатный). Старые ключи Magic сброшены, годится только свежий ключ с 21st.dev/mcp. Поэтому 21st **не ставится молча**: сначала объясняешь, потом подключаешь только с ключом самого ученика.

## Что сказать ученику до подключения (простыми словами)

- Что это: подсказчик с библиотекой готовых красивых кусочков сайта (кнопки, цены, карточки). Claude ищет их и вставляет в твой проект.
- Нужен аккаунт на 21st.dev (вход через Google или GitHub, бесплатно) и личный ключ: это как пароль для Claude, чтобы 21st знал, что это ты.
- Платное названо заранее: на бесплатном тарифе поиск работает, а установка компонентов ограничена (на 03.11.2026: 2 установки в день); ИИ-генерация интерфейса идёт за отдельные платные кредиты. Условия сверь на 21st.dev/pricing, не обещай цифры.
- Куда уходит: текст запроса («нужна таблица цен») и ключ уходят на сервер 21st.dev, когда Claude их ищет. Файлы проекта сам MCP не отправляет.
- Ключ не вставляй в чат. Ты просто скопируешь его кнопкой «Копировать», остальное сделаю я.

Ученик не хочет или не может сейчас (нет аккаунта, нет времени) — не настаивай, запиши «21st: ждёт ключ» и иди дальше. На уроке без 21st можно, это дополнение.

## Шаги

1. Ученик открывает https://21st.dev/mcp, входит и нажимает «API key» → создаёт ключ → **копирует** его (Cmd+C на Mac, Ctrl+C на Windows). В чат не вставляет.
2. Проверь буфер, не показывая его: длина от 16 до 200 символов, без пробелов. Если не так — ученик скопировал не то, попроси скопировать ключ заново.
3. Подключи через буфер обмена. Ключ в команде не пишется, в ответе команды он скрыт.
4. Очисти буфер обмена.
5. Проверь `claude mcp list`: строка `21st:` со статусом «Connected» значит ключ рабочий. «Needs authentication» значит ключ не принят: скопировать заново и повторить (сначала `claude mcp remove 21st -s user`).
6. Скажи ученику перезапустить сессию: новый MCP виден после перезапуска.

### Mac

```bash klyuch-21st-mac
CLIP_LEN="$(pbpaste | wc -c | tr -d ' ')"
pbpaste | grep -Eq '^[A-Za-z0-9_.:-]+$' && [ "$CLIP_LEN" -ge 16 ] && [ "$CLIP_LEN" -le 200 ] || { echo "в буфере не похоже на ключ"; exit 1; }
claude mcp remove 21st -s user >/dev/null 2>&1
claude mcp add --scope user --transport http 21st https://21st.dev/api/mcp --header "x-api-key: $(pbpaste)" >/dev/null 2>&1 && echo "21st подключён"
printf '' | pbcopy
claude mcp list 2>/dev/null | grep '^21st:'
```

### Windows (PowerShell)

```powershell klyuch-21st-win
$clip = (Get-Clipboard -Raw).Trim()
if ($clip -notmatch '^[A-Za-z0-9_.:-]{16,200}$') { 'в буфере не похоже на ключ'; return }
claude mcp remove 21st -s user *> $null
claude mcp add --scope user --transport http 21st https://21st.dev/api/mcp --header "x-api-key: $clip" *> $null
$clip = $null
Set-Clipboard -Value ' '
claude mcp list 2>$null | Select-String '^21st:'
```

(Windows не проверено на реальной машине.)

## Что нельзя (ключ утекает в чат)

- **Никогда не запускай `claude mcp get 21st`**: эта команда печатает ключ открытым текстом. Статус смотри только через `claude mcp list`.
- Не читай и не печатай `~/.claude.json` (ключ лежит там; файл доступен только владельцу).
- Не проси ученика вставить ключ в чат. Вставил — скажи удалить сообщение, создать новый ключ на 21st.dev/mcp (старый отозвать) и повторить шаги.
- Не клади ключ в код проекта, `.env` проекта или GitHub: он нужен только MCP на этом компьютере.

## Отвечая «у меня есть 21st?»

Проверь только имя сервера в списке (блок проверки в `ustanovka.md` печатает имена, не значения) и при желании `claude mcp list`. Ключ не показывай и не пересказывай.
