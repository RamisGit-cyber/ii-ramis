## Заметки по безопасности, которые знает наставник

- **Установку выполняет скрипт плагина** (`hooks/kit-install.sh`), который приложение запускает при старте сессии вне песочницы, с правами пользователя. Скрипт публичный, в репозитории виден целиком; он качает только то, что в таблице выше, на закреплённых версиях. Хук `--notice` ничего не ставит и печатает одну строку. `II_RAMIS_NO_KIT=1` и `status: declined` отключают его.
- Remotion и HyperFrames: SKILL.md у них, как у любого навыка, исполняется как инструкция. Версии закреплены (тег и коммит); обновлять только после просмотра изменений. Сам CLI HyperFrames скрипт не запускает. Если ученик запустит `npx hyperframes` сам, у CLI по умолчанию включена статистика (`~/.hyperframes/config.json`): предложи `HYPERFRAMES_NO_TELEMETRY=1` или `hyperframes telemetry disable`. Облачные функции HyperFrames (вход в HeyGen, API-ключ) в набор не входят.
- Скрипт запускает `npx` из временной папки с `NPM_CONFIG_REGISTRY` на официальный npm: так `.npmrc` или `node_modules` случайного проекта не подменят закреплённый пакет. MCP Playwright в 2.5 ставится в `~/.ii-ramis/mcp` и подключается по абсолютному пути, поэтому папка проекта на него не влияет. Кто подключил Playwright раньше через `npx` (урок 4), у того подключение осталось прежним: скрипт «уже стоит» не трогает; при желании скажи «переподключи Playwright», удали старое (`claude mcp remove playwright -s user`) и запусти установку.
- superpowers ставится из маркетплейса Anthropic актуальной версией маркетплейса (закрепление коммита на стороне маркетплейса не перепроверено), у плагина есть свои хуки. Agent Reach: закреплён zip, но его Python-зависимости при `uv tool install` берутся с PyPI без закрепления, а `agent-reach setup` выполняет код автора.

- Установщик навыков (`npx skills`) по умолчанию шлёт анонимную статистику (название репозитория и навыка). Блоки установки выставляют `DISABLE_TELEMETRY=1` и `DO_NOT_TRACK=1`. Если ученик ставит навык сам, добавь эти переменные в команду.
- Навыки и плагины «работают с полными правами агента»: чужой текст из SKILL.md Claude исполняет как инструкцию. Поэтому ставим только из списка выше и из ссылок, которые дал сам ученик или Рамис, и просматриваем SKILL.md (`skill-po-ssylke.md`).
- Agent Reach: на PyPI есть пакет с тем же именем `agent-reach`, **это другой, чужой пакет**. Ставить только из zip релиза Panniantong/Agent-Reach. Каналам по умолчанию логин не нужен. Каналы с логином (Reddit, соцсети, LinkedIn) копируют вход из Chrome ученика в отдельный браузер Agent Reach, поэтому **не добавляй их без явной просьбы ученика** и объясни, что копируется.
- Поиск по своим материалам не уходит наружу. Но `agent-reach` и `find-skills` ходят в интернет по запросу ученика (GitHub, YouTube, skills.sh), это их назначение.
