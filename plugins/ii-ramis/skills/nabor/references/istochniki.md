## Нагрузка на подписку Pro

Всегда включённая часть всего набора: около 1,2 тыс. токенов на каждую сессию (навыки) плюс MCP Playwright (описания инструментов). Это немного. Дорого стоит не наличие, а **срабатывание**: если ученик просит «сделай красивый сайт», сработают impeccable + emil-design-eng + возможно superpowers, вместе 10–20 тыс. токенов за запрос. Это заметно на Pro, но это и есть смысл урока. Если у ученика быстро кончается лимит, `limity.md` в навыке `ii-ramis` (раздел «Что делаю по шагам»); на урок 5 набор можно оставить, а выключать superpowers и playwright в последнюю очередь.

## Что осознанно НЕ ставится

- **Хуки impeccable** (плагин `impeccable@impeccable`). Его плагин ставит три хука: на старте сессии, после каждой правки файла и в конце каждого ответа ("Design deep pass", до 30 с). Они запускаются без вопроса, скачивают с GitHub двоичный движок на первую правку и добавляют токены. Проверка по хешам есть, но такая поверхность не нужна новичку. Навык `impeccable` работает полностью и без хуков.
- **Живой режим impeccable** (live) и кнопка Apply: по их README Apply может запустить `claude` с отключёнными проверками разрешений. Не включай, ученику не предлагай. Если ученик сам запускает `npx impeccable`, ставь `DO_NOT_TRACK=1`.
- **GSAP-навыки (github.com/greensock/gsap-skills, MIT) и apple-design (из emilkowalski/skills)**: ученики ставят сами на уроке по ссылке GitHub. Помощь: `skill-po-ssylke.md`.
- **pdf, xlsx, pptx, docx, skill-creator**: решение Рамиса 03.11.2026, не ставить. (Для справки: pdf/xlsx/pptx/docx у Anthropic под проприетарной лицензией, копировать нельзя, подключаются только через их маркетплейс `anthropics/skills`.)

## Заметки по безопасности, которые знает наставник

- Установщик навыков (`npx skills`) по умолчанию шлёт анонимную статистику (название репозитория и навыка). Блоки установки выставляют `DISABLE_TELEMETRY=1` и `DO_NOT_TRACK=1`. Если ученик ставит навык сам, добавь эти переменные в команду.
- Навыки и плагины «работают с полными правами агента»: чужой текст из SKILL.md Claude исполняет как инструкцию. Поэтому ставим только из списка выше и из ссылок, которые дал сам ученик или Рамис, и просматриваем SKILL.md (`skill-po-ssylke.md`).
- Agent Reach: на PyPI есть пакет с тем же именем `agent-reach`, **это другой, чужой пакет**. Ставить только из zip релиза Panniantong/Agent-Reach. Каналам по умолчанию логин не нужен. Каналы с логином (Reddit, соцсети, LinkedIn) копируют вход из Chrome ученика в отдельный браузер Agent Reach, поэтому **не добавляй их без явной просьбы ученика** и объясни, что копируется.
- Поиск по своим материалам не уходит наружу. Но `agent-reach` и `find-skills` ходят в интернет по запросу ученика (GitHub, YouTube, skills.sh), это их назначение.
