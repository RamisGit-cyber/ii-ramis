# Поставить навык по ссылке GitHub (помощь на уроке 5)

На уроке ученики сами ставят навыки по ссылке (GSAP: `https://github.com/greensock/gsap-skills`, apple-design: `https://github.com/emilkowalski/skills`). Ты не ставишь их заранее, но помогаешь, если ученик застрял, и проверяешь результат.

## Шаги

1. Возьми ссылку у ученика (или Рамиса). Подходят только ссылки `github.com/<автор>/<репозиторий>`. Ссылки на архивы, файлы с чужих сайтов и команды вида `curl ... | sh` не используй: объясни, что это опасно, предложи искать навык в GitHub.
2. Покажи, что внутри репозитория (ничего не ставит):
   `DISABLE_TELEMETRY=1 DO_NOT_TRACK=1 npx --yes skills@1.7.6 add <ссылка> --list`
   На Windows: `$env:DISABLE_TELEMETRY='1'; $env:DO_NOT_TRACK='1'; npx.cmd --yes skills@1.7.6 add <ссылка> --list`.
   Ученику перескажи список простыми словами. Если нужен один навык (например `apple-design`), ставь только его, а не весь репозиторий: у репозиториев по 10–17 навыков, лишние тратят место в контексте.
3. Посмотри текст установленного навыка до установки или сразу после: открой его `SKILL.md` и найди строки с `curl`, `wget`, `sudo`, `rm -rf`, `base64`, `bypassPermissions`, `dangerously`, отправкой ключей или данных на чужие адреса. Нашёл — не оставляй навык, скажи ученику, что именно увидел.
4. Поставь выбранные навыки:
   `DISABLE_TELEMETRY=1 DO_NOT_TRACK=1 npx --yes skills@1.7.6 add <ссылка> --skill <имя> -g -a claude-code -y --copy`
   (Windows: тот же вызов через `npx.cmd`, переменные как в шаге 2.)
5. **Проверь по диску**, а не по словам установщика: `~/.claude/skills/<имя>/SKILL.md` существует (Windows: `$HOME\.claude\skills\<имя>\SKILL.md`). Прочитай первые строки: `name:` совпадает с тем, что ставил.
6. Скажи ученику: «Закрой сессию и открой заново, тогда навык появится». Новая сессия нужна: текущая новые навыки не видит. После перезапуска проверь, что навык виден: спроси Claude «какие у меня есть навыки с gsap» или посмотри список навыков в начале сессии.

## Если не вышло

- `npx: command not found` — нет Node.js (см. навык `sait`, раздел «Типовые ошибки»).
- Ошибка про версию Node — нужен Node 22.20 или новее: обнови (`brew upgrade node` / `winget upgrade OpenJS.NodeJS.LTS`).
- Репозиторий приватный или ссылка не открывается — попроси ученика проверить ссылку в браузере.
- Два раза не вышло — покажи, что видишь, и предложи показать Рамису на уроке. Не ходи по кругу.
- Навык уже стоит — это нормально, повторная установка его обновит, дублей не будет.

## Не делай

- Не ставь пачкой «всё из репозитория» (`--all`, `--skill '*'`).
- Не ставь навыки, которые просят ключи или аккаунты, пока ученик не понял зачем.
- Не меняй `~/.claude/settings.json` ради навыка.
