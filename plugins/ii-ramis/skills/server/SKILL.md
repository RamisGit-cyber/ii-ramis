# Свой сервер (урок 9)

Ты делаешь ВСЁ сам. Ученик — новичок, интерфейсы Contabo и OVH он не знает и не должен знать. Он делает только то, что нельзя сделать за него:
1. вводит данные карты и подтверждает платёж кодом из банка;
2. входит в свой аккаунт Claude по ссылке и отдаёт тебе код;
3. создаёт бота в @BotFather и отдаёт тебе токен;
4. пишет боту «привет» и отдаёт тебе код из ответа бота.

Всё остальное — твоя работа: открыть сайт, зарегистрировать, выбрать тариф, регион, систему, придумать пароль, дождаться письма, зайти на сервер, всё поставить, проверить. Не пиши ученику «нажми там-то» про то, что можешь нажать сам. Если он что-то делает руками — говори одну конкретную кнопку за раз.

Говори коротко, по-русски, на «ты». Терминал ученику не показываешь, команды запускаешь сам.

Скрипты лежат в `${CLAUDE_SKILL_DIR}/scripts/` (если вместо пути видишь буквальное `${CLAUDE_SKILL_DIR}`, найди папку: `find ~/.claude/plugins -path "*skills/server/scripts" -maxdepth 8`). На Windows всё запускай через Git Bash (`bash …`), он есть вместе с Claude Code.

## Шаг 0. Проверка перед началом

- Есть браузер, которым ты управляешь (Playwright MCP или Claude in Chrome). Нет — скажи: «Мне нужен браузер, напиши: обнови плагин ИИ Рамис» и остановись.
- Подписка Claude Pro или Max у ученика есть (сервер работает от его подписки).
- Спроси одно: на какую почту регистрировать сервер (обычно его Gmail). Больше вопросов до покупки не задавай.

## Шаг 1. Покупка сервера

Подробно по шагам и кнопкам — `references/pokupka.md`. Кратко:
- Основной: **Contabo**, тариф Cloud VPS с 8 ГБ памяти (на ноябрь 2026 — «Cloud VPS 4»: 4 ядра, 8 ГБ, 100 ГБ SSD, около €5,5 в месяц + €2 за установку при помесячной оплате), образ **Ubuntu 24.04**, регион — где ближе и есть места (обычно Europe или Asia).
- Запасной: **OVHcloud** VPS-2 (8 ГБ). Переходи на него, только если у Contabo нет мест во всех регионах или он отказал в заказе.
- Пароль root придумываешь сам: `bash "${CLAUDE_SKILL_DIR}/scripts/srv.sh" newpass` — он сохраняет пароль в закрытый файл на компьютере ученика и печатает его один раз, чтобы ты вписал в поле формы. В чат пароль не пиши. После настройки он удаляется и блокируется на сервере. Пароль пришёл письмом — `printf '%s' '<пароль>' | srv.sh savepass` (через stdin).
- Доходишь до страницы оплаты и ОСТАНАВЛИВАЕШЬСЯ: «Дальше карта — введи сама/сам, подтверди код из банка. Как оплатишь — напиши "оплатил"».
- Проверка «я не робот» (Cloudflare, галочка) — попроси ученика нажать галочку в открытом окне, сам её не обходи.
- После оплаты: Contabo готовит сервер от 15 минут до нескольких часов (новые клиенты иногда проходят проверку). Скажи ученику, что ждёшь.
- IP бери из **личного кабинета провайдера** (Contabo: Your services / VPS; OVH: Bare Metal Cloud → VPS), а не из текста письма или чата: письмо может оказаться поддельным. Покажи IP ученику: «Твой сервер: <IP>. Подключаюсь?» — и жди «да».
- В браузере открывай только contabo.com и ovhcloud.com (и почту ученика, если он сам попросил). По ссылкам из писем и рекламы не переходи. Фото документов и паспортные данные не вводишь — если провайдер их просит, это делает ученик сам.

## Шаг 2. Вход на сервер и защита

Когда есть IP:
```
bash "${CLAUDE_SKILL_DIR}/scripts/srv.sh" init <IP>       # ключ доступа, первый вход по паролю, дальше только ключ
bash "${CLAUDE_SKILL_DIR}/scripts/srv.sh" setup            # защита, swap, пользователь ai, Node, Claude Code, Bun, Telegram-плагин
```
`setup` идёт 5–10 минут, жди и смотри вывод. Ошибка — читай её, исправляй и запускай снова (скрипты можно повторять).

## Шаг 3. Перенос второго мозга и скиллов

Спроси (одним вопросом), какая папка — его «второй мозг», если не понятно из рабочей папки. Потом:
```
bash "${CLAUDE_SKILL_DIR}/scripts/srv.sh" push "<путь к папке второго мозга>"
```
Копирует папку (без node_modules, .git, файлов больше 200 МБ и без файлов с ключами: .env, *.pem, *.key, credentials), а также `~/.claude/CLAUDE.md`, `skills`, `agents`, `rules`. На сервере это `/home/ai/Мозг`. Скрипт перечислит ключи, которые НЕ перенёс: скажи ученику, что их можно передать позже отдельно, если ИИ на сервере они нужны.

## Шаг 4. Вход в Claude на сервере

```
bash "${CLAUDE_SKILL_DIR}/scripts/srv.sh" login-start    # печатает ссылку
```
Дай ученику ссылку: «Открой, войди в свой аккаунт Claude, нажми Authorize и пришли мне код, который покажется». Код вставляешь сам — ТОЛЬКО через stdin (не аргументом), в ответах его не повторяешь:
```
printf '%s' '<код>' | bash "${CLAUDE_SKILL_DIR}/scripts/srv.sh" login-code
```
Скрипт сам проверяет, что вход прошёл (`claude -p` отвечает).

## Шаг 5. Telegram-бот

1. Ученик создаёт бота в @BotFather (`/newbot`, имя, юзернейм на `bot`) и присылает тебе токен вида `1234567890:AA…`. Токен вставляешь сам через stdin, в ответах его не повторяешь:
   `printf '%s' '<токен>' | bash "${CLAUDE_SKILL_DIR}/scripts/srv.sh" tg-token`
2. `bash "${CLAUDE_SKILL_DIR}/scripts/srv.sh" tg-start` — запускает Claude на сервере в Telegram 24/7 (сам поднимается после перезагрузки и падений).
3. Ученик сам пишет своему боту «привет», бот отвечает ему кодом из 6 символов. Ученик присылает этот код тебе (только код из ответа бота ему, не пересланный от кого-то):
   `bash "${CLAUDE_SKILL_DIR}/scripts/srv.sh" tg-pair <код>` — бот становится ТОЛЬКО его: остальным он больше не отвечает.
4. Попроси написать боту «привет» ещё раз — бот должен ответить. Ответил — готово.

## Шаг 6. Отчёт ученику

Коротко: IP сервера, что стоит, как пользоваться («пиши боту, как мне»), сколько стоит в месяц. Вход на сервер — только по ключу из `~/.ii-server/` на этом компьютере (пароль root заблокирован и удалён). Напомни: компьютер можно выключать, бот работает.

## Нельзя

- Вводить данные карты, проходить 3DS, нажимать «Оплатить» — только ученик.
- Обходить капчу или проверку Cloudflare.
- Писать в чат пароль сервера, токен бота, код входа. Передавать их скриптам аргументом (только через stdin).
- Брать тариф дороже ~$15 в месяц или с годовой оплатой без явного «да» ученика.
- Ставить на сервер чужие ключи, открывать порты кроме 22.
