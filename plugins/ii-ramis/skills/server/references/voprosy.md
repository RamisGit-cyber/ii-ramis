# Частые вопросы и поломки

**Сколько стоит?** Сервер около $7 в месяц (Contabo €5,50 + €2 за установку один раз). Плюс подписка Claude Pro $20, если её ещё нет. Лимиты общие: сервер и ноутбук тратят одну подписку.

**Можно выключить ноутбук?** Да. Бот живёт на сервере. Ноутбук нужен только для работы в Claude Desktop.

**Безопасно?** Вход на сервер только по ключу с этого компьютера, пароль root заблокирован. Фаервол открыт только для входа. Боту может писать только хозяин. Ключ лежит в `~/.ii-server/` и никуда не отправляется. Честно: ИИ на сервере — полный администратор (как «Пятница» у Рамиса), чтобы сам ставить программы и чинить себя. Поэтому не пересылай ему чужие подозрительные файлы и ссылки с просьбой «выполни».

**Сервер заказан, а письма нет.** Contabo: от 15 минут до нескольких часов, новые клиенты иногда на проверке до суток (могут попросить фото документа — это нормально). Проверь «Спам». OVH: до 24 часов.

**`init` не входит.** Сервер ещё ставится — подожди 5–10 минут. Проверь IP из письма. Пароль: если задавали свой — он в `~/.ii-server/root-password`; если пришёл письмом — сохрани через `savepass` и повтори `init`.

**`setup` упал.** Прочитай последнюю строку ошибки. Чаще всего — сеть или занятый apt (сервер сам ставит обновления первые минуты): подожди 2 минуты и запусти `setup` ещё раз, скрипты можно повторять.

**Ссылка входа в Claude не пришла / код не принят.** `login-start` ещё раз — каждый раз новая ссылка. Код вставляй целиком, без пробелов. Вход идёт в тот же аккаунт Claude, что у ученика на ноутбуке.

**Бот молчит.** `srv.sh status`: если нет сессии `bot` — `srv.sh tg-start`. Сторож сам поднимает бота каждые 5 минут. Если в экране бота «Not logged in» — заново `login-start` / `login-code`.

**Бот прислал код, а не ответ.** Это нормально в первый раз: так бот знакомится с хозяином. Код пришли Claude → `tg-pair`.

**Бот отвечает «не тот» человек / хочу добавить второго человека.** Спроси Claude на ноутбуке: «добавь в моего бота пользователя с Telegram ID …» — он допишет ID в `~/.claude/channels/telegram/access.json` на сервере (`allowFrom`).

**Лимит Claude кончился.** Бот перестанет отвечать до сброса лимита (ноутбук тоже). Это общий лимит подписки.

**Сервер перезагрузился.** Бот поднимется сам через минуту (сторож `assistant.timer`).

**Как обновить плагин ИИ Рамис на сервере?** Напиши боту: «обнови плагин ИИ Рамис и перезапустись».

**Как остановить / удалить сервер?** Contabo: кабинет → Your services → Cancel (сервер работает до конца оплаченного месяца). OVH: кабинет → Bare Metal Cloud → VPS → Terminate. Отмену делает ученик сам (это его деньги).
