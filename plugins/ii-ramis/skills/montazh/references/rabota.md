# Как собирается ролик: команды и план

Везде `<скрипты>` — папка `scripts/` рядом с навыком (см. SKILL.md), `<проект>` — папка проекта ученика, `<имя>` — короткое имя ролика без пробелов (латиница или кириллица, цифры, дефис). Команды запускай из папки проекта. На Windows пути те же, кавычки двойные.

## Расшифровка (один раз на видео)

```
uv run --with faster-whisper==1.2.1 --with av==15.1.0 <скрипты>/transcribe.py . исходники/<видео>.mp4 _монтаж/<имя>/transcript.json --lang ru
```

- Сначала `mkdir _монтаж/<имя>` внутри проекта. Первый аргумент (`.`) — папка проекта; видео и результат обязаны лежать внутри неё, результат только в `_монтаж/`, по ссылкам (symlink) скрипт не пишет.
- `--lang ru` для русской речи; для английской `en`; для смешанной или кыргызской не задавай язык (определится сам). Кыргызский распознаётся слабо: слова придётся поправить вручную по слуху ученика, предупреди об этом.
- `--model base` быстрее, но менее точно (по умолчанию `small`, ~500 МБ скачается с huggingface.co один раз, репозиторий Systran, версия закреплена; дальше работает без сети). Всё считается на компьютере ученика, видео никуда не уходит.
- На слабом компьютере 40 секунд речи считаются 15–60 секунд.
- Результат: слова с началом и концом в секундах. Это основа для резки и субтитров.

Если `uv` не запустился или модель не скачалась: скажи честно, что именно, и предложи ученику вставить текст речи самому (тогда время слов задай приблизительно по длине видео и скажи, что резка будет грубее).

## План монтажа `_монтаж/<имя>/plan.json`

```json
{
  "name": "reel-1",
  "source": "исходники/talk.mp4",
  "keep": [[0.2, 5.6], [5.8, 11.0]],
  "cards": [
    {"s": 0.3, "e": 1.9, "text": "Я настроил себе", "accent": "настроил"}
  ],
  "inserts": [
    {"s": 6.0, "e": 8.0, "file": "ассеты/logo.png", "pos": "top", "width": 420}
  ],
  "face": {"x": 150, "y": 440, "w": 700, "h": 800},
  "style": {"accent": "#FFD400", "layout": "single", "size": 80, "bottom": 1450, "backdrop": true},
  "frame": {"scale": 0.86, "top": 60},
  "split": {"seam": 900, "panels": [{"s": 6.0, "e": 10.0, "file": "ассеты/screen.png"}]},
  "crop_x": 0.5,
  "music": {"file": "ассеты/music.mp3", "below_voice_db": 18}
}
```

Все времена `keep`, `cards`, `inserts` — в секундах **исходника** (как в расшифровке); скрипт сам пересчитает их под склеенный ролик.

- `keep` — какие куски оставить. Всё между ними вырезается (паузы, оговорки, дубли). Границы сами сдвигаются к границам слов с запасом, слова не режутся.
- `cards` — субтитры. `text` — ИСПРАВЛЕННЫЙ текст (не сырое распознавание), 1–3 слова, до ~18 знаков. `accent` — слово цветом (не обязательно). Одна карточка за раз: пересечения скрипт срезает.
- `inserts` — картинки только из `ассеты/` (PNG с прозрачностью лучше). `pos`: `top` (над лицом, y≈240) или `bottom`, либо свои `x`, `y`. Показывать 1,5–2,5 с, по смыслу сказанного, не на лице.
- `face` — рамка лица в готовых координатах 1080×1920 (после `frame`/кадрирования). Включает лоб, глаза, рот и подбородок, с запасом на движение головы: смотри кадры ВСЕГО ролика и бери самую низкую точку подбородка и самые крайние положения головы. Критик проверяет, что надписи и вставки в эту рамку не заходят (с запасом 30 px).
- `style.layout`: `stack` (тонкая строка + слово крупно под ней, по умолчанию) или `single` (одна строка, акцентное слово цветом). Лицо крупное и низко, мало места под подбородком — `single` и 1–2 слова на карточку.
- `style.size` по умолчанию 84; `bottom` — где нижний край надписи (по умолчанию 1380, выше 1460 скрипт не пускает); `backdrop: true` — тёмная плашка под текстом (когда фон светлый: рубашка, стена); `accent`, `text` — цвета `#RRGGBB` (из бренда ученика).
- `frame` — «отъезд»: человек уменьшается до `scale` (0.7–1.0) и ставится выше, на размытый фон. Нужен, если лицо занимает почти весь кадр и под подбородком нет места для субтитров.
- `style.preset` — `afisha` включает стиль «Афиша» (карточки с `theme`, `main`, `over`, `hand`, `strike`), `split` включает сплит-скрин; подробности и примеры в `references/stili.md`.
- `crop_x` — для горизонтального исходника: какую часть по ширине взять (0 лево, 0.5 центр, 1 право); человека посмотри на кадре и выбери так, чтобы лицо было по центру ролика.
- `music` — файл внутри проекта: из `ассеты/` ученика или копия трека из библиотеки плагина (`_монтаж/<имя>/music.mp3`, откуда копировать и про атрибуцию CC BY: шаг 4 пункт 5 в `SKILL.md`). `below_voice_db` — насколько музыка тише голоса (по умолчанию 18). Нет музыки — `null` или без ключа.

## Сборка и выдача

```
uv run <скрипты>/montage.py build <проект> _монтаж/<имя>/plan.json
uv run <скрипты>/critic.py <проект> _монтаж/<имя>/plan.json
uv run <скрипты>/montage.py export <проект> _монтаж/<имя>/plan.json
```

- `build` создаёт `_монтаж/<имя>/base.mp4` (чистое видео с голосом), `subs.ass` (субтитры), `final.mp4` (итог 1080×1920, H.264, 30 к/с, звук выровнен до около −14 LUFS). Занимает от 1 до 5 минут, предупреди ученика, что компьютер на это время занят.
- `export` берёт `final.mp4` и кладёт в `готово/<имя>.mp4`; если файл уже есть, пишет `<имя>-v2.mp4`. Запускай только после критика.
- Файлы `_монтаж/` — рабочие; ученику про них говорить не нужно, кроме `готово/`.

## Приёмы

- **Резка.** Паузы длиннее ~0,35 с ужимай (оставляй 0,15–0,2 с воздуха), оговорки («э-э», повтор слова, оборванная фраза) вырезай целиком по словам. Начало: не больше ~0,2 с тишины до первого слова. Конец: последняя фраза звучит целиком, потом ~0,3 с.
- **Субтитры = язык ролика.** Лицо и рот не закрывать ничем. Низ кадра (~420 px) и правая колонка (~140 px) заняты кнопками Instagram: надпись ставь ближе к y≈1180–1400 (нижний край не ниже 1460). Шрифт Onest лежит в плагине, в нём есть ң ө ү. Мягкая тень, без обводки; один основной цвет, один акцентный. Размер одинаковый по всему ролику.
- **Хук.** В первые 2 секунды: сразу речь и первая надпись. Лучше, если первая фраза — самое интересное, а не «привет, меня зовут».
- **Ритм.** Каждые ~2 с что-то меняется: новая карточка, вставка, акцент. 3 секунды одной картинки без события — дыра.
- **Музыка** тихая, под голос; нет музыки в `ассеты/` — предложи трек из библиотеки плагина (`assets/music/`, по настроению) или свою, в интернете сам не ищи. Трек из библиотеки под CC BY 4.0: в описание ролика нужна атрибуция (текст в `assets/LICENSES.md`), скажи ученику.
- **Горизонтальное видео** (запись экрана, урок 16:9): станет вертикальным обрезкой по `crop_x`; если важно видеть всё, скажи, что для Reels обычно снимают вертикально.

## Стиль «Афиша»: маска человека

Нужна, чтобы слово-тема стояло ЗА головой (`stili.md`; маска RVM, как у Монтажки; шрифты Афиши и два режима рисования: HyperFrames и запасной ASS, подробно там же). Окружение маски ставится один раз по «да» ученика (`nabor/references/ustanovka.md`, «Маска человека»), питон лежит в `~/.ii-ramis/mask/bin/python` (Windows: `%USERPROFILE%\.ii-ramis\mask\Scripts\python.exe`). Порядок:

```
uv run <скрипты>/montage.py build <проект> <план>        # 1. собирает base.mp4 (без маски слово-тема пока над головой)
<питон маски> <скрипты>/segment.py <проект> _монтаж/<имя>/base.mp4 _монтаж/<имя>/mask.mp4   # 2. маска человека
uv run <скрипты>/montage.py build <проект> <план>        # 3. итог: слово-тема за человеком
```

`segment.py` читает только видео проекта и пишет только `_монтаж/<имя>/mask.mp4`, в сеть не ходит. Маски нет (нет окружения, ученик отказался, шаг 2 не прошёл): пропусти шаг 2, скажи ученику «слово-тема встанет над головой, а не за ней» и предложи поставить маску. Результат посмотри глазами: слово реально за головой, лицо и рот не закрыты, края маски без «дыр».
