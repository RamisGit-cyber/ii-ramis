Как использовать: ученик говорит «сделай как референс 12». Бери из этого файла структуру сценария (раздел «Сценарий») и приёмы монтажа (раздел «Монтаж»), тему и слова подставляй свои. Не копируй фразы и кадры автора.

## Сценарий

**Крючок (первые 1–3 с).** «Your Claude Code can now build full video games just like a real developer with one plugin.» («Твой Claude Code теперь может строить полноценные игры как настоящий разработчик, одним плагином»). На экране заголовок «Claude Code Now Builds Full Video Games» с игровыми кадрами в рамке.

**Структура по секундам.**
- 0–7 с — Крючок: можно собрать игру целиком одним плагином; кто-то на GitHub выложил репозиторий.
- 7–13 с — Что внутри: 77 навыков для Unreal, Unity, Godot и веб-игр (цифра «77» крупно).
- 13–19 с — Удобство: навыки выбирать не надо, просто описываешь игру, он сам подберёт под движок и задачу (демо в терминале).
- 19–28 с — Широта: от движения игрока до платформера и арт-дирекшена; игровые ассеты как в студии.
- 28–37 с — Результат: от старта до публикации и монетизации в App Store/Steam; призыв «Comment «game»» с лицом крупно.

**Ключевые фразы (по смыслу, не копировать).**
- You never even have to pick the skills yourself (даже выбирать не надо)
- 77 навыков, от движения игрока до арт-дирекшена
- From start to finish, then publish and monetize

**Тон и длина.** Дружеский, быстрый, энергичный. Длина: 37 с.

**Призыв к действию.** Комментарий, слово GAME (пришлю ссылки).

**Что взять в свои ролики (шаблоны своими словами).**
- Цифра в центре идеи («77 навыков») крупно на вставке.
- «Не надо выбирать, он сам подберёт» — лёгкость как довод.
- Финальный результат: «от нуля до магазина приложений».

## Как повторить

- **Чем делать:** Сплит-скрин (как 09). В montazh: «Сплит-скрин» с заголовком сверху.
