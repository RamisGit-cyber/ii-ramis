# Референс 06 — Anatomy: навык, который по одной команде рисует интерактивные схемы

Чужое видео и кадры сюда не вложены (авторские права): только описание и ссылка.

Как использовать: ученик говорит «сделай как референс 06». Бери из этого файла структуру сценария (раздел «Сценарий») и приёмы монтажа (раздел «Монтаж»), тему и слова подставляй свои. Не копируй фразы и кадры автора.

## Сценарий

**Крючок (первые 1–3 с).** «Одна команда превращает идею в такую живую схему — перед тобой открытый пример анатомии». Цепляет обещанием «одна команда» и картинкой двигателя ракеты, который дышит дымом прямо в кадре.

**Структура по секундам.**
- 0–8 с — Крючок и что это: одна команда → живая схема; навык для Claude Code и Codex; команда установки на экране.
- 8–21 с — Показ 1: двигатель (раздвигаешь узлы) и игровой автомат (монета, механизм, экран).
- 21–30 с — Польза: объяснить устройство продукта или поставить интерактивный объект на сайт вместо картинки; ещё примеры: компьютер, волновая ванна.
- 30–38 с — Честная оговорка и как пользоваться: красивый механизм не доказывает правильность, физику проверяй; задавай предмет, действие, результат; начни с того, что зритель должен понять.

**Ключевые фразы (по смыслу, не копировать).**
- Одна команда → готовая схема
- Красивый механизм не доказывает правильность объяснения (честная оговорка добавляет доверия)
- Для своей идеи задаёшь предмет, действие и результат (формула запроса)

**Тон и длина.** Спокойный объясняющий, как преподаватель; без крика и без «купи». Длина: 38 с.

**Призыв к действию.** Мягкий: ссылка в описании («попробуй Anatomy…»), слова в комментарии не просят.

**Что взять в свои ролики (шаблоны своими словами).**
- Формула запроса «предмет + действие + результат» — классная подсказка для учеников.
- Честная оговорка в конце: «проверь сам» — добавляет доверия.
- Показывать 3–4 разных примера подряд, не один.

## Монтаж

- **План:** Только графика: белые изометрические 3D-схемы (ракетный двигатель, игровой автомат, компьютер, волновая ванна). Говорящей головы нет.
- **Как часто меняется кадр:** Крупная смена сцены каждые 4–10 с (светлый фон ↔ тёмный), внутри — зум в круглое «увеличительное стекло» каждые 2–4 с; текст меняется каждые ~1,5–2 с.
- **Субтитры:** Слева сверху, около 310 px из 1920, выровнено влево. Шрифт без засечек ~42 px, 2 строки по 4–7 слов. Тёмный текст на светлом / белый на тёмном. Прочитанные слова блёкнут (серые), текущее слово зелёное тёмное. Пословная подсветка по ходу речи.
- **Вставки и переходы:** Подписи-выноски с цифрами у деталей («Турбонасос», «Камера»), панель кода внизу, круг-лупа, выезжающий на деталь. Переходы: плавный зум-блюр, смена светлой/тёмной темы.
- **Анимация текста:** Детали раздвигаются/собираются, дым из сопла, лупа наезжает.
- **Звук:** Музыка ровная, пауз нет; эффектов по записи не выделить.
- **Обложка / первый кадр:** Первый кадр: ракетный двигатель в дыму + строка «Одна команда превращает идею…» + код внизу.

## Как повторить

- **Чем делать:** HyperFrames или готовая интерактивная схема в записи. Для Классики — не подходит (нет лица).
- **Что положить в папку проекта:** Записи 2–3 готовых схем (скрин-рекордер), фраза-формула, текст по фразам.
- **Как сказать навыку:** «сделай как референс 06, про <моя тема>». Навык montazh берёт стиль из строки «Чем делать», тему и слова спрашивает у ученика.
